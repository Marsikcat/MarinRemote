# MarinRemote

Удалённый доступ к ПК с Windows без своих серверов: экран, мышь, клавиатура, буфер обмена
и файлы. Соединение — QUIC через [iroh](https://iroh.computer): ПК находят друг друга по
публичному ключу. iroh сам пробивает NAT, а если не получилось, гонит зашифрованный трафик
через публичные ретрансляторы n0. Ретранслятор видит только шифротекст.

В одной программе две роли: **«Этот ПК»** (к нему подключаются) и **«Подключиться»**
(вы подключаетесь к другому ПК).

> **Состояние: этап a из пяти** — соединение, авторизация, подтверждение, контакты,
> журнал. Картинка экрана (этап b), мышь и клавиатура (c), файлы (d), буфер обмена и
> установщик (e) — следующие этапы.

## Запуск из исходников

Нужен Python 3.12 для Windows 10/11.

```bat
python -m venv venv
venv\Scripts\python -m pip install -r requirements.txt
venv\Scripts\pythonw app.py
```

Данные лежат в `%APPDATA%\MarinRemote`: `settings.json` (ключ устройства, контакты,
доступ), `journal.jsonl`, `auth_state.json`, `app.log`.

### Два экземпляра на одном ПК (для проверки)

`tools\run_two.bat` запускает экземпляры 1 и 2 (`MARINREMOTE_INSTANCE=1/2`). У них свои
порты, а данные лежат в `%TEMP%\MarinRemote-dev-N`. Настоящий профиль они не трогают.

### Тесты

```bat
venv\Scripts\python -m pip install pytest
venv\Scripts\python -m pytest -q
```

`tools\screens.py` рисует окна программы в PNG без вывода на экран.

## Как подключиться

1. На удалённом ПК: «Этот ПК» → «Копировать код» (`mr-…`). Передайте код любым способом.
2. На своём: «Подключиться» → вставьте код. ПК в той же сети (и в Radmin VPN) видны
   в списке и без кода.
3. На удалённом ПК появится окно «… хочет подключиться». Там отмечают права и жмут
   «Разрешить». Если 30 секунд никто не ответит — отказ.
4. Чтобы дальше подключаться в один клик:
   - **на своём ПК:** «Сохранить в контакты»;
   - **на удалённом:** в окне запроса отметьте «Запомнить это устройство → дальше
     подключаться без подтверждения».

   Чтобы подготовить это заранее, когда у удалённого ПК никого не будет: там «Доступ» →
   «Добавить устройство по коду» и вставьте код своего ПК.

## Порты

| Порт | Протокол | Зачем |
|---|---|---|
| 8895 (+100 на тестовый экземпляр) | UDP | QUIC: всё содержимое сеансов. Если порт занят, берётся случайный |
| 8894 | UDP | поиск в локальной сети, общий для всех экземпляров |

С MarinCall (8890, 8891) не пересекаются: обе программы можно запускать одновременно.
Через интернет хватает исходящих соединений. Входящий порт нужен только для прямого
подключения в локальной сети, если брандмауэр не пропустил программу.

## Модель безопасности

- **Личность = ключ.** ID устройства — его публичный ключ Ed25519. QUIC/TLS доказывает
  ключ при каждом соединении и шифрует всё. Секретный ключ лежит в `settings.json`
  и никуда не передаётся.
- **Решает хост.** По умолчанию каждое подключение подтверждает человек у ПК:
  30 секунд, галочки прав (просмотр / управление / файлы / буфер обмена), по таймауту — отказ.
- **Без подтверждения** входят только запомненные устройства:
  - режим «сразу» — их ключ и есть пропуск;
  - режим «по паролю» — нужен пароль, заданный на хосте. Хранится хэш argon2id (соль,
    256 МБ, 3 прохода).

  Устройству, которого нет в списке, пароль не поможет. Всё это выключается одним
  переключателем «Пускать запомненные устройства без подтверждения».
- **Подбор пароля:**
  - на устройство 3 попытки без задержки, дальше 2, 4, 8 … с, до 15 минут;
  - больше 20 неудач за 10 минут от кого угодно — пауза для всех;
  - счётчики переживают перезапуск.
- **Окна подтверждения не спамятся:** одно на устройство, три сразу; после отказа —
  минута тишины.
- **До входа хост ничего не принимает.** Датаграммы и стримы, отправленные до входа,
  отбрасываются по метке сеанса.
- **Права проверяет хост** на каждом сообщении. Действия сверх выданных игнорируются
  и пишутся в журнал.
- **Сеанс видно:**
  - красная рамка по краю экранов (зрителю её не видно, клики проходят сквозь неё);
  - панель поверх окон «кто подключён · права · Отключить»;
  - значок в трее с красной точкой.
- **Аварийная клавиша** `Ctrl+Shift+Alt+F12` (меняется в «Доступе») рвёт все сеансы
  мгновенно, где бы ни был фокус. После неё повторный вход требует нового подтверждения.
- **Повторный вход после обрыва.** Хост выдаёт зрителю одноразовый токен, привязанный
  к его ключу. Если сеть пропала, в течение минуты он входит снова без подтверждения.
  «Отключить», аварийная клавиша и уход зрителя токен аннулируют.
- **Настройки доступа блокируются**, пока подключены с правом управления: их нельзя
  поменять удалённо.
- **Журнал** («Журнал», `journal.jsonl`): запросы, решения, неудачные пароли, сеансы
  с правами и длительностью, нарушения прав.

Протокол подробно: [docs/PROTOCOL.md](docs/PROTOCOL.md).

## Ограничения MVP

- Программа работает с правами обычного пользователя. Windows (UIPI) не даёт такому
  процессу управлять окнами, запущенными от администратора. Запрос UAC, экран блокировки
  и экран входа тоже недоступны. Нужна служба от имени SYSTEM — это второй этап.
- Доступ работает, пока пользователь вошёл в систему и MarinRemote запущен.
- Ctrl+Alt+Del и Win+L Windows не даёт перехватить и передать.

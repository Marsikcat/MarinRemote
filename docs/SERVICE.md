# Служба ввода Windows

Единая установка добавляет `MarinRemoteInput` в Program Files. Служба нужна для ввода
в повышенные окна, например Диспетчер задач, из обычного приложения MarinRemote.
Поддерживается уже вошедший администратор с доступным связанным повышенным токеном.
Экран входа, блокировка и защищённый рабочий стол UAC не поддерживаются.

## Границы полномочий

- Сеть, подтверждение подключения и проверка права `control` остаются в обычном
  приложении. Служба не открывает сетевые порты и не читает профиль MarinRemote.
- Служба SYSTEM принимает только локальные named pipes. Наблюдаемый Windows PID
  клиента должен принадлежать установленному защищённому exe. SID и идентификатор
  входа в его токене должны совпасть с удостоверением клиента канала.
- Помощник запускается из фиксированной папки Program Files со связанным повышенным
  токеном этого пользователя, в его сеансе на `winsta0\default`. SYSTEM-токен
  не переносится в пользовательский рабочий стол. Клиент не задаёт путь запуска,
  рабочую папку или окружение помощника.
- Приложение и помощник проверяют сервер канала через SCM: PID работающей службы,
  её команду запуска и учётную запись LocalSystem. Для приватного канала помощника
  служба также проверяет PID запущенного процесса.
- Протокол помощника ограничен проверенными событиями мыши, клавиш, освобождением
  ввода и проверкой связи. Запуск команд, файловые операции и произвольные WinAPI
  через этот канал отсутствуют. Размер сообщения ограничен 4096 байтами.

## Завершение и обновление

При отзыве управления или уходе последнего управляющего зрителя приложение
закрывает канал. Помощник освобождает удерживаемые им клавиши и кнопки при EOF,
ошибке или отсутствии сообщений в течение трёх секунд. Переполнение очереди
также разрывает канал; старые события после переподключения не воспроизводятся.

Служба отказывается работать из исходников, другой папки или папки-ссылки,
а также при доступной обычному пользователю записи в проверенные пути установки.
Встроенное обновление скачивает единый подписанный установщик и запускает его через
Windows с запросом повышения прав. При отказе приложение продолжает работать.
Прежняя Admin-установка обновляется поверх с сохранением внутреннего AppId; перед
переходом с per-user установки её нужно удалить обычным способом, сохранив данные.
Её деинсталлятор из пользовательской папки никогда не запускается новым установщиком
с повышенными правами. Перед заменой файлов установщик дожидается
остановки службы; перед удалением файлов — удаления её регистрации.

## Проверка

`tests/test_service.py` проверяет допустимые события, защиту окон хоста,
освобождение ввода, отказ на защищённом рабочем столе, переполнение очереди,
локальные каналы Windows, удостоверения сторон и очистку при ошибке запуска.
Эти тесты не устанавливают службу и не вызывают настоящий SendInput.

Живая проверка 0.4.0 выполнена с временной защищённой установкой и отдельными
профилями: обычный зритель отправил цифры через QUIC обычному хосту, служба
доставила их в тестовое повышенное окно. После аварийного завершения хоста
окно получило отпускание удерживаемого Shift. Временная служба, помощники
и папка установки после проверки удалены.
